## Batch 3 — zoeken, filters, bediening

Volledige analytische STEP-export daarvan blijft vereist vervolg. Bronbasis: [STEP Tools FACETED_BREP](https://www.steptools.com/docs/stp_aim/html/t_faceted_brep.html) en [CLOSED_SHELL](https://www.steptools.com/docs/stp_aim/html/t_closed_shell.html).
